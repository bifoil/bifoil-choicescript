# Bifoil artwork

`bifoil.svg` is the original, font-independent vector logo for Bifoil Foundation. The IntelliJ plugin uses the same
shapes in `editors/intellij/src/main/resources/META-INF/pluginIcon.svg`. VS Code uses the checked-in 256 × 256 PNG
rendering at `editors/vscode/icon.png`. Keeping that rendering in the repository avoids adding an image renderer to the
build.
